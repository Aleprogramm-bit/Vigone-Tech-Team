🖥️ Description of Open Smart OS
Open Smart OS is a lightweight and fast operating system designed to provide a professional environment without relying on any other systems.
It aims to be simple to use, stable, and suitable for both modern computers and lower‑power machines.
The goal is to deliver a clean, intuitive, and fully autonomous experience.

👤 Author
Developed by Aleprogramm as a project focused on creating an independent and optimized operating system.

📌 Main Features
Fully independent operating system
Simple interface for all user levels
Optimized performance even on modest hardware
Professional and clean structure
Active development in progress

🔧 System Requirements
RAM: 1 GB
CPU: Intel Pentium 4 or equivalent
Storage: 20 GB SSD/HDD
USB Support: under verification
Checksum: not provided

📥 Download Information
Open Smart OS will be released as an ISO image once the build is ready. The ISO will allow installation on real hardware and virtual machines. The download link will be published on the official page when the release is finalized.
💽 Installation Options
Installation via ISO image
