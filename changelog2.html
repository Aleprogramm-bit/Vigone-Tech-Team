Registro aggiornamenti

Qui vengono pubblicate tutte le modifiche, le nuove funzionalità e lo storico delle versioni di LorenzoOS.

Storico Versioni

  • v4.0

    Introduzione dell'utility Sticky Notes per appunti rapidi sul desktop.

  • v3.0

    Aggiunti Colorizer, App Manager e avviso di disconnessione in stile Windows 3.x.

  • v2.0

    Introduzione del comando Esegui, schermata di errore BSOD e disabilitazione della CLI di default.

  • v1.9

    Implementazione del supporto multi-utente.

  • v1.8

    Integrazione del Terminale CLI.

  • v1.7

    Nuove personalizzazioni cromatiche del sistema.

  • v1.6.5

    Aggiunto il gioco Tris.

  • v1.6

    Nuova applicazione Orologio.

  • v1.5

    Aggiunta dell'utility Winver per le informazioni di sistema.

  • v1.4

    Introduzione del Task Manager per la gestione dei processi.

  • v1.3.1

    Integrazione del classico gioco Snake.

  • v1.0

    Rilascio iniziale con desktop personalizzabile, orologio RTC, blocco note, calcolatrice, impostazioni, screensaver, schermata di login e menu applicazioni.
