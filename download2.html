Requisiti minimi

LorenzoOS è un sistema operativo leggero basato su architettura x86, eseguibile su VirtualBox anche con soli 32MB di RAM (o meno). Si tratta di un sistema 'Live OS': questo significa che l'intero software risiede in un file ISO e può essere avviato direttamente, senza alcuna necessità di installazione sull'hard disk.
